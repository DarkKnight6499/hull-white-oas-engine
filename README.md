# hull-white-oas-engine

A standalone Python library for Hull-White calibration, callable and putable bond pricing, and option-adjusted spread analysis of mortgage pass-throughs. It combines European closed forms, a curve-fitted recombining trinomial tree, and exact Gaussian Monte Carlo discounting. All example inputs and market targets are **synthetic**, generated by seeded code. Runtime execution needs no network access.

## Run

Only NumPy and pandas are runtime dependencies. With those packages already available, run from the project root:

```powershell
python -m unittest discover -s tests -v
python examples/run_all.py
```

For library use, install the package into an environment with the build tooling available:

```powershell
python -m pip install -e .
```

The example runner imports the source directly, so installation is unnecessary for examples or tests. It regenerates CSV and Markdown tables under `examples/output/`, including calibration, swap repricing, tree convergence, bond risk, key-rate durations, mortgage convergence and static PSA cash flows. [The generated report](examples/output/report.md) collects the main tables. [configuration.json](examples/output/configuration.json) records seeds, assumptions and runtime versions. [validation.json](examples/output/validation.json) records full-precision results.

```python
from hw_oas import FixedRateBond, HullWhite, HullWhiteTree, synthetic_curve
from hw_oas.oas import solve_oas, z_spread

curve = synthetic_curve()
model = HullWhite(curve, a=0.075, sigma=0.012)
bond = FixedRateBond(
    maturity=10,
    coupon=0.045,
    calls={2.0 + 0.5 * i: 100.0 for i in range(16)},
)
tree = HullWhiteTree(model, horizon=bond.maturity, steps=400)
synthetic_market_price = tree.bond_price(bond, spread=0.0025)
oas = solve_oas(lambda spread: tree.bond_price(bond, spread), synthetic_market_price)
z = z_spread(bond, curve, synthetic_market_price)
```

The usage snippet fixes reference parameters. The validation tables below use parameters fitted to the noisy synthetic quote grid. Rates and spreads are decimal, continuously compounded where used for discounting. Bond and mortgage prices use the configured initial face or pool balance.

## Methodology

- **Curves:** positive discount factors with log-linear interpolation, instantaneous forwards and constant terminal-forward extrapolation. A CSV loader accepts `time,zero_rate`, with positive year fractions and decimal continuous zero rates. Annual fixed-pay swaps versus idealized compounded SOFR OIS bootstrap recursively and reprice to par.
- **Analytic model:** the centered Gaussian short rate plus a deterministic curve-fitting shift reproduces input discount factors exactly. Closed forms cover conditional zero-coupon bonds, bond options, Jamshidian coupon-bond options, European swaptions, caplets and floorlets. Normal probabilities use `math.erf`.
- **Calibration:** a custom Nelder-Mead optimizer fits positive mean reversion and volatility in log coordinates. Equal-weight relative price residuals define the objective. Synthetic ATM normal vols originate from reference-model prices, then receive seeded noise and convert back through Bachelier pricing.
- **Tree:** exact OU conditional moments determine nearest-center trinomial branches. The Hull-White Arrow-Debreu alpha-fitting principle calibrates each discount interval. Backward induction handles European and Bermudan bond options, issuer calls and investor puts. Exercise redemption excludes the current coupon, which is paid separately. Event dates must align with the grid.
- **Bond OAS and risk:** a custom safeguarded Brent solver adds a constant spread to discounting and matches the target price. Effective duration, convexity and key-rate durations rebuild the pricing engine on bumped curves at the original OAS. Model parameters remain fixed; exercise is reevaluated. Z-spread discounts promised payments without optionality.
- **Mortgages:** surviving loans amortize monthly; prepaid principal follows SMM converted from CPR. Servicing and guarantee fees reduce investor interest. Both static PSA and a stylized refinance-incentive CPR rule are provided, with seasoning and burnout. WAL weights repayment times by principal.
- **Monte Carlo:** endpoints and integrated short rates are sampled jointly from their exact Gaussian distribution. Antithetic pair averages define independent observations for standard errors. Cached path cash flows make OAS inversion deterministic for a fixed sample. Curve-bump risk uses common random numbers and recalculates rate-dependent prepayments.

The mortgage-rate proxy is the simulated month-end short rate plus a fixed spread, floored at zero. It is a deliberate simplification of the rate available to borrowers. Refinance, burnout, mortgage-proxy and fee parameters are **stylized and uncalibrated**, with no empirical or regulatory interpretation. The PSA ramp was verified in the Federal Reserve's [Principal Payments on the Federal Reserve's Securities Holdings](https://www.federalreserve.gov/econres/notes/feds-notes/principal-payments-on-the-federal-reserves-securities-holdings-20170616.html), **MBS Principal Payments**, paragraph describing the PSA benchmark. No regulatory parameter is used or asserted.

[docs/methodology.md](docs/methodology.md) specifies the formulas, exercise timing, Gaussian simulation, uncertainty calculation and conventions.

## Limitations

- A single Gaussian factor and constant volatility do not represent a volatility smile, stochastic volatility or multifactor yield-curve dynamics. Negative short rates are possible.
- Log-linear discounts imply forward jumps. The exact Gaussian representation fits these curves through deterministic short-rate jumps; `theta` describes only the regular drift between knots. This is not a smooth classical drift at curve knots.
- The tree uses an exact-moment nearest-center variant of Hull-White branching. It follows the alpha-fitting principle, with finite-step and payoff discretization error. Coupon and exercise dates must align with the grid; simultaneous call and put priority is unsupported.
- Swaps and caplets use simplified accrual conventions. There are no calendars, business-day adjustments, accrued-interest settlement, daily SOFR mechanics, multiple curves, default risk or credit recovery.
- Mortgage parameters are stylized. The short-rate-linked mortgage proxy omits lender margins, mortgage basis dynamics and borrower heterogeneity. Prepayments use month-end incentive observations. Defaults, delayed remittances and seasonality are omitted.
- Reported uncertainty covers Monte Carlo sampling only. Calibration, CPR specification and mortgage-proxy uncertainty are excluded. OAS uncertainty is a local approximation; no confidence interval for duration or convexity is supplied.
- All targets are synthetic. Closed-form and reconciliation validation establish internal numerical consistency, not production readiness or empirical pricing accuracy. Local execution is validated; the hosted CI workflow has not been run from this directory.
